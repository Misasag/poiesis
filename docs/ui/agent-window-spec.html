主要な画面遷移

Agent→Explorerアイコンで選択Repositoryのファイルツリーを開く
Explorer→ファイルを選択してmain areaのEditorで開く
Agent→Changes 1で選択SessionのChangesを開く
Changes→Evidenceを選択してEditorの該当行へ移動する
Any view→Agentアイコンで会話へ戻る。会話状態は保持する

状態保持の契約

状態単位切替時の扱い
選択RepositoryWindowExplorer・Search・Gitの対象として共有
選択SessionRepository会話、Composer、Changes選択を復元
TaskSession会話内の実行記録。左サイドバーには並べない
Change SetTaskChangesで表示し、Agentへ戻っても選択を保持
開いているEditorRepositoryAgent／Changesへ移動しても閉じない

現在の設計判断

状態判断理由
決定D1-B Agent-first layoutAgentを主画面とし、必要時に下位レイヤーへ降りる
決定「質問」ボタンを置かない同じComposerから自然に追加質問できる
草案Repository配下にSessionを表示Repository中心と会話履歴への到達性を両立する

草案Changesをmain areaで開くSemantic Diffの縦幅とEvidence可読性を確保する
