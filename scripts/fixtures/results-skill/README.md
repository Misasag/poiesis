# pomodoro-web

シンプルなポモドーロタイマーのWebアプリ。ビルド不要・素のHTML/CSS/JavaScriptで動作します。

## 要件

- 作業タイマーは25分
- 1〜3サイクル目の作業後は5分休憩、4サイクル目の作業後は15分の長い休憩に切り替わる
- 長い休憩の終了後、サイクル数を1/4に戻す
- ヘッダーの下に現在のサイクル数を「1/4」の形式で表示する
- スタート / 一時停止 / リセットができる
- 残り時間を大きく表示し、ブラウザのタブタイトルにも反映する
- 今日完了した作業タイマーの回数を大きく表示する（休憩・中断・リセットは加算しない）
- 作業回数はブラウザに保存し、再読み込み後も保持する。端末の現地日付で集計し、日付が変わると表示を切り替える（保存が利用できない場合はページを開いている間だけ保持）
- 依存ライブラリなしで、`index.html`をブラウザで開くだけで動作する
